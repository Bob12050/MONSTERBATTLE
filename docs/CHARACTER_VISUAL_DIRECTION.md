# ASTRA CROWN キャラクタービジュアル方針

## 基本比率

今後のロスター全体は、**人型・人系 8 : ガッツリモンスター型 3**を目安にする（厳密な11体単位ではなく、長期的に約70〜75%を人型寄りに保つ）。

ここでいう「人型」は人間種族だけを意味しない。見た目・シルエットが人物キャラクターとして成立するものを含む。

### 人型・人系に含むデザイン
- 剣士 / 騎士 / 武闘家 / 侍 / 忍者
- 魔導士 / 巫女 / 神官 / 錬金術師
- 天使 / 悪魔 / 神 / 女神
- 獣人 / 竜人 / 妖精 / エルフ系
- 機械人 / アンドロイド / 人型兵器
- 人型の異形・魔族

### ガッツリモンスター型
- 四足獣
- ドラゴン
- 巨大幻獣
- 昆虫・甲殻系
- スライム等の非人型生物
- 機械獣
- 巨大な異形

## 種族と見た目は分離する

`race` は性能上の種族であり、見た目を固定しない。

例:
- 人型の竜騎士 → 種族: ドラゴン
- 人型の女神 → 種族: 神 / 幻獣などゲーム内分類に合わせる
- 人型の獣戦士 → 種族: 獣
- 巨大狼 → 種族: 獣

これによりキラー等のゲーム性能を維持したまま、人物中心のロスターを作れる。

## 入手先ごとの目安

### ガチャ限定
人型を強めにする。特に目玉★5は人物として印象に残るデザインを優先する。ただしドラゴン等のモンスター型目玉も定期的に混ぜる。

目安: **人型 8〜9 : モンスター 1〜2**

### 降臨
人型ボスと大型モンスターの両方を出す。ガチャよりモンスター型を増やし、ラック99で集めたくなるボス感を出す。

目安: **人型 6〜7 : モンスター 3〜4**

### 通常ドロップ
世界の生態系を感じさせる役割もあるため、モンスター型を比較的多くしてよい。低レアの雑魚すべてを仲間にする必要はない。

目安: **人型 4〜6 : モンスター 4〜6**

## キャラ設計テンプレートへの追加項目

新規キャラは性能設計時に以下を必ず指定する。

- `visualType`: `humanoid` / `monster`
- ビジュアルモチーフ
- 年齢感（人型の場合。具体年齢でなく少年・青年・成人など）
- シルエット上の特徴
- 武器 / 魔法 / 戦闘スタイル
- 進化前→進化後で何が変わるか

## 量産時のチェック

10〜20体単位で追加候補を作るたび、以下を確認する。

1. 人型とモンスター型の長期比率が約8:3から大きく外れていないか
2. 人型が女性キャラ・剣士など一種類に偏っていないか
3. 男性 / 女性 / 中性的 / 仮面・鎧など、人物シルエットに幅があるか
4. ガチャだけに魅力的な人物デザインが集中していないか
5. 降臨にも人気が出そうな人物キャラを配置できているか
6. モンスター型を減らしすぎて世界観から「MONSTER」の感覚が消えていないか
7. 性能上の種族と見た目を必要以上に一致させていないか

## 既存・試作キャラの扱い

既に実装済みのキャラを急いで削除・置換はしない。今後の追加で比率を人型寄りに補正する。

未実装の試作キャラは、性能・入手先・役割を流用しつつ、必要に応じて人型へ再デザインしてから実装する。

例:
- 星炎鳥 フレアセラフ → 星炎を纏う翼人・天使系の人型へ再設計可能
- 天律獣 オルディナのような性能枠 → 人型神官・天律騎士などの方向へビジュアル再設計可能
- ガッツリモンスターとして魅力があるドラゴン・獣・甲虫は、そのままモンスター枠として残す

## 方針

ASTRA CROWNは「モンスターだけを集めるゲーム」ではなく、**人物・神・悪魔・獣人・機械人・ドラゴン・幻獣などを同じロスターで集めるキャラクター収集RPG**として展開する。
