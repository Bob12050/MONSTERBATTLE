## Wave 1 ロスター評価

### 属性

5属性を3体ずつにして、最初の試作段階では属性偏重を避けた。

### 入手先

通常6、降臨5、ガチャ限定4。ガチャだけでBOXの主要役割が埋まらない比率にしている。

### ラック

降臨5体は全員ラック99を狙う意味を持たせた。ガチャ4体はラック99を前提にしない。通常6体は図鑑・ニッチ適正・任意育成が中心。

### アビリティの重なり

同じアビリティが複数体に付くことを許容しつつ、完全に同じセットは作っていない。特に `party_guard`, `heal_boost`, `self_guard` などの汎用能力は複数キャラで共有し、属性・入手先・他アビリティ・スキルで差別化する。

### 固有能力

試作ガチャ★5では、単純な倍率上昇ではなく「奥義を撃った後」「スキルを使った後」という行動変化型を試している。これらはプロトタイプであり、実装前に個別バランス確認を行う。

## 次の判断

この15体は一括実装しない。まず以下を見て、実装候補を数体ずつ選ぶ。

1. 現在のクエストで用途が成立するか
2. 新しいクエストを作らないと存在理由がないキャラになっていないか
3. 現行14体の価値を不必要に奪わないか
4. 通常ドロップを序盤で配りすぎる配置にならないか
5. ガチャ・降臨・通常の役割分担が保たれているか

問題がなければ、このテンプレートを正式なキャラ追加フローとして使う。
